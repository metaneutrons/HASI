# Security policy

HASI is an incomplete prototype. It does not connect to Hochschule Hannover
identity systems, live anny credentials, or knowledge sources. Its local demo
uses synthetic identities and in-memory data.

Report suspected vulnerabilities through
[GitHub Private Vulnerability Reporting](https://github.com/metaneutrons/HASI/security/advisories/new).
Do not disclose a vulnerability in a public issue. Maintainers aim to
acknowledge private reports within five business days and will coordinate a
fix and disclosure timeline with the reporter.

Before a stable release exists, the latest default-branch revision is the only
supported code line. No versioned release is currently supported.
